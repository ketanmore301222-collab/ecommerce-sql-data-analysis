# E-Commerce SQL Data Analysis

## Project Overview
This project analyzes an e-commerce database using MySQL.

## Database Tables
- Customers
- Orders
- Order Items
- Products
- Payments

## Analysis Performed
- Total Revenue
- Best-Selling Products
- Top Customers by Spending
- Cancelled Orders
- Order Status Analysis

## SQL Concepts Used
- JOIN
- GROUP BY
- SUM()
- COUNT()
- ORDER BY
- WHERE
- Aggregate Functions

## Tools
- MySQL
- MySQL Workbench

## Key Learning
This project helped me understand how multiple tables are connected using
primary and foreign keys and how SQL can be used to answer business questions.
